PURPOSE
The Installation Qualification verifies and documents WS-010, Battery Pack Verification Workstation, conforms to specifications and is installed as described in the Installation Instructions, MWI-210 Rev D - WS-010 Workstation Installation (IQ).
SCOPE
This protocol qualifies WS-010, Battery Pack Verification Workstation, the equipment and installation in a sectioned off area at MedAI located at 100 Main St. NE Suite 700, Springfield, IL 60001.
REFERENCES
QSP-025 Rev B, Process Validation
MWI-210 Rev D - WS-010 Workstation Installation
QSF-084 Rev C - Equipment IQ Checklist
METHODS
The Test Operator will follow the Equipment Installation Qualification (IQ) Checklist using the MWI-210 Rev D - WS-010 Workstation Installation as required and record results. Any deviations will be recorded as known issues, reviewed and approved.
