Purpose
This document summarizes the verification and validation activities for the MX1 Portable X-ray System which includes the E1 Emitter, C1 Cassette, H1 Wired Chargers (Qty 2), Collimation Pucks and P1 Case. The F1 Foot Pedal and K1 Cart were assessed as accessories to the MX1 System. The T1 Tablet with MedAI Device App (APP) was included as support equipment.
Scope
Verification was performed on MX1 Rev E and MX1 Rev F configurations according to PLN-P01-065 Rev B, MX1 Verification and Validation Plan.
MX1 Rev G modifications did not require additional verification and validation.
Software verification for v3.0.0, v3.1.0, v3.2.0, and v3.2.1 was performed on MX1 Rev E.
Software verification for v4.0.0, v4.0.1, was performed on MX1 Rev F.
Software verification for application of Detector Calibration Map was performed using MX1 Rev F with SS v4.1.0.

Software Version Summary
The MX1 Software System history for v3.x.x  is recorded in MEMO-P01-635 - MX1 Software Version History.  In summary, the following software releases used for verification and validation testing are listed in chronological order.
MX1 SS v3.0.0 and v3.1.0 were used in conjunction with MX1 Rev E design verification units to complete initial verification and validation testing for the MX1 System.
MX1 SS v3.2.0 was developed for the Summative Usability study and validated during the study in September 2024. See ECR-470.
MX1 SS v3.2.1 was developed to allow for remote updating of the operating system and clarify cybersecurity requirements in response to FDA requests for additional information. Penetration Testing and additional verification testing determined by engineering review was conducted on this software version. See ECR-574 for verification activities.
MX1 SS v4.0.0 was developed and verified to work with the new PCBAs and other MX1 BOM-055 Rev F hardware. See ECR-549 for verification activities.
MX1 SS v4.0.1 included bug fixes for a database permissions issue and Time of Flight calibration issue with production activities. See MEMO-P01-765 - Changes to the MX1 Lidar TOF Calibration Sequence and MEMO-P01-766 - Resolution to Bugs Involving MariaDB Directory for further details (ECR-587).
MX1 Software System changes post Phase 3 Conditional Closure are listed here for additional information. Note, MX1 SS v4.1.0 was included in the verification and validation summary table due to software specific testing of the application of detector calibration maps being completed with this version.
MX1 SS v3.3.0 was developed post Phase 3 Conditional Closure in response to the AINN response for K24146 and to address outstanding anomalies. Reference ECR-602 for verification activities.
MX1 SS v3.4.0 was developed post Phase 3 Conditional Closure in response to the AINN response for K24146 and verified in VVPR-P01-236 - MX1 Software System, v3.4.0 Protocol and Report. Additional Fuzz testing was completed to address FDA questions (See VVPR-P01-238). Reference ECR-643.
MX1 SS v4.1.0 was developed post Phase 3 Conditional Closure for the application of Detector Calibration Maps and other feature updates listed in ECR-661. Refer to ECR for verification activities.
Anomalies identified in MEMO-P01-826 - MX1 Software System, v4.1.0, Unresolved Anomalies, shall be addressed and verified prior to future release. If outstanding anomalies exist they will be risk assessed to determine acceptability prior to launch.

Software anomalies identified in MEMO-P01-826 - MX1 Software System, v4.1.0, Unresolved Anomalies shall be addressed or risk assessed for acceptability prior to commercialization.
