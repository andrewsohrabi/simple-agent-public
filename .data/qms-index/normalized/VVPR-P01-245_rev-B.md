Protocol Section
STUDY PURPOSE
The purpose of this study is to demonstrate that MX1 Portable X-ray System’s Software System meets the requirements as stated in MEMO-P01-776 - MX1 Software Requirements Specification as it relates to the following features:
Offset correction using light and dark raw frames
Application of gain and defect calibration maps
OBJECTIVE AND SCOPE
The primary objective of this study is to verify the MX1 Software System appropriately applies the detector gain and defect maps generated by S10098 MX1 Detector Calibration Tool to meet requirements as documented in MEMO-P01-776 when using a calibrated detector and test images.

REPORT SECTION
PROTOCOL DEVIATIONS
For SRS 42.3 (The SS shall apply a defect calibration map to raw images), an adjusted map that differs from standard defect map generation was manually created. The only difference between the original map and the adjusted map was the image bit-size. The default maps are created at 16bit pixel depth, which was creating issues during application of the maps. The adjusted defect map was a copy of the original 16bit image, but reduced to 8bit depth. All defect locations remained unchanged, and values in the map are still all 0 or 1. The original and adjusted maps are attached in VVPR-P01-245, Attachment 6 - VVPR-245_Defect_Gain_Maps.zip. Additionally, the changes made to the MX1 Detector Calibration Tool (S10098) to create 8bit maps will be described and shown in its 1.1.0 release.

RESULTS
DISCUSSION
All MX1 Software System verification tests passed, with acceptable deviation on  following tests:
Table 1, SRS-42.3 (The SS shall apply a defect calibration map to raw images) - Defect maps generated by MX1 Detector Calibration Tool (S10098) are 16 bit images. MX1’s image processing algorithm can only apply 8 bit maps, not 16 bit. As a result, the defect map used during the test was a copy of the original 16bit image, but reduced to 8bit depth.
The deviation required to pass this SRS will prevent this software version from being distributed as the MX1 Software System on the MX1 device. However, it may be used during the E1 Performance Qualification (PQ) at the contract manufacturer as these deviations do not affect device firmware.
The required changes to continue passing without deviation of this SRS shall be addressed in the next MX1 SS version and uploaded to MX1 devices during the MX1 PQ at the contract manufacturer during end of line verification using WS-012, MX1 End of Line Verification workstation.
